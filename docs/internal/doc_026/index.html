2023【心理行为课第一期】开课通知

您好！欢迎参加2023【心理行为课第一期】，课程报到及相关信

息如下：

一：报到时间

报到：2023年5月9日（周二）

课程时间：5月10日到5月30日（21天），5月31日返程。时间

安排比较紧张的同学，也可以选择5月30日老挝时间下午17：00以后

返程。

二：报到地点

老挝南塔省磨丁经济特区慧兰酒店

四：食宿安排

1、培训期间餐费自理：

餐费：酒店自助早餐38元人民币一位；中、晚餐每人一顿25元人

民币；（素食供餐：4个素菜、1个素汤、米饭供应）

2、实行三餐制（老挝时间）：

早餐8：00；中餐12：00、晚餐17：30。

说明：如果住宿酒店者可以免费提供早餐，其他非住宿酒店学员

按照38元一位。酒店附近有饭店可以用餐，距离很近，学员也可以自

由选择在外就餐，价格参考：一碗盖浇饭18--25元。

在您⼊住酒店时，如需预定酒店⾃助餐券，请与酒店前台服务⼈

员办理。21天课程，您可以一次性购买全部餐票，也可以分成每周购

买1次，但需要提前至少2天跟酒店前台购买，便于酒店及时准备食材，

一经购买餐券后概不退票退费。若您使⽤不了全部餐券，您可以选择

与他⼈共同购买一套餐券；或者可以选择不购买酒店餐券自行解决就

餐问题。

报到当天（9⽇晚）&课程结束当晚（30⽇晚），酒店不提供⾃

助餐，您可以在酒店单点或附近餐馆⾃理。

培训期间全程不允许录音、照相、摄像，违反课堂规则的学员会

被列入不信任名单，不能申请“清一会员”，后期也不接受其他课程

报名，还会影响您的推荐人信用，以及您的孩子申请入学，还请大家

大家做好全部精力投入的准备。您的投入和参与越多，收获也就越大。

核心体系。本课程属于内部独家课程，因此对学员要求“只用不说”，

不能对任何人分享课程内容，包括您的亲人。请您记住课程规则。

本课程一共21天，全面解析并实践心理行为教育原则和理念，属

于“一门深入”的学习方式，学到后可用于您的生活，学习，教育，

工作，管理各个方面，具有很强的实用性和操作性。

第一讲的作业会在上课前公布，请各位学员们在上课的前一天（5

月9日老挝时间晚上21：00前）提交作业至群在线文档，管理员会提

前一周开贴。如果没有完成作业者，将会被助教拒之门外，不能进课

室上课，请大家认真对待。
