住宿和餐食通知 更新通知 初级一期

关于校方提供的免费校舍，和酒店的餐食安排，我们获得了更加准确的信息，现补充如

下。请大家谨慎做出选择：

一、关于今日校舍

由于校舍目前还在筹备阶段，原定9 月份正式投入使用，离现在还有半年时间，所以

目前有些设备还无法到位。具体情况如下：

1、供电系统不稳定，可能会随时断电；

2、可能暂无热水供应系统（仅冷水）；

3、房间内设施简陋（仅床铺和简易床品）。

4、饮食需自行解决，所需物品需自行采购。

5、五月份月是磨丁的雨季，多雨时节，可能来往不便。

二、关于慧兰酒店：

1、山长的高级心理行为课程，是在初阶心理课上进一步深入剖析和运用，山长的课程

安排非常紧凑。我们的授课主会场、课后讨论教室、和自习教室，以及用餐地点，

全都在慧兰酒店内。入住酒店有助于您静下心来，不用花费时间在每天往返路程，

能够全身心投入课程，在七天后完成身心灵全方位的蜕变！

2、和同学们一起上课，一起下课，吃住同时。有老师的指引，有伙伴的陪伴，善莫大

焉。

3、酒店房间环境清新典雅，设施完备。有免费双早，中晚餐也有自助餐服务，四菜一

汤，仅25 元/餐。（酒店自助早餐如下图）

关于今日免费校舍的住宿，目前，海外基金会已联系厂家赶制家具和硬件设施，但因时

间紧迫，厂家人手不足，到时不一定能够满足全部需求。还请大家谅解

。目前我们对宿

舍和慧兰酒店的情况进行了详细对比。

大家可以根据新的信息，重新考虑自己的住宿安排。表格也会开放给大家重新修改！

三、关于餐食

关于餐食方面，我们推荐您选择酒店内的餐饮：

1、磨丁附近的餐馆基本是夫妻档小店，恰逢五一放假会有比较多游客在外就餐，

您需要花费时间点餐排队，可能影响午休等宝贵时间。

2、酒店周围的小餐馆，餐饮质量不能保证。而慧兰酒店的食物原材料，都是提前

从国内订购的运送过来的，厨师和餐食卫生方面受到规范监管的，品质方面可以保证。

3、同时，另一个选项是，我们的小助教也会为您提供免费的基本粥品和豆瓣酱，

如果有学员在有时不想花太多时间在吃饭上，想吃的简单一些，这也是另一个可选项。

因此，虽然在外面就餐，或许可以省下一些钱，但您却需要花更多的时间和精力在

琐事上面，而影响课程体验感。相比之下，这是不太划算的。关于餐食大家可以谨慎考

虑。

四、关于餐票的购买规则

1、酒店的自助餐票是一套一套售卖。我们21 天的课程，会先请大家预订前7 天课程

的餐票，中晚餐总共是14 餐，所以第一周的一整套餐票就是14 张，一餐是25 元，所

以购买一套餐票是350 元人民币。然后后续两周，也会以一周14 张餐票为单位，一套

一套进行售卖，后续两周的餐票售卖，可以等大家来了磨丁后，我们会再具体统计和购

买。

同时，售卖的餐票也是可以和其他学员共享使用的，只需要在每7 天的周期内使

用完即可。

2、酒店的早餐，由于是豪华的中式自助餐，提供的餐食品种也更多，所以是38 元一

餐。如果是选择住酒店的学员，是赠送免费双早的，无需单独购买。

3、因为信息最近才确定下来，后续表格的餐票部分，会进行一些修改，需要麻烦大家

重新填写信息。餐食板块将会有两栏可以选择：【是否购买一套中晚餐券（14 张）】和

【是否需要购买早餐？】（需要填写具体数量）。

4、由于酒店需要从国内提前采购食材，送到磨丁也需要时间，所以是需要大家提前预

订的！我们在报道当天，会在前台根据大家的报名餐食信息，按量发放餐券。等到快开

课时，酒店是不接受“空降”和临时订餐的喔，因此请大家注意尽快填报自己的餐食和住

宿信息！

温馨提示：

1、四月份中是磨丁的泼水节（相当于新年），属于旅游旺季。慧兰酒店是磨丁特区唯一

一家四星级酒店，旅客住宿需求很大。请计划入住酒店的学员，尽快填写表格及时预定！

2、大家也可以在选择酒店时，和其他学员沟通拼房。没有选择拼房的学员，我们会随

机安排同性学员入住。

3、关于酒店房型

由于酒店的三人间数量很少，而慧心课又有很多年龄较大，或是一家人来参加课程的学

员，所以我们计划优先将三人间提供给慧心课学员，方便他们照顾家人。这点请大家理解一

下。所以三人间就暂时不对大家开放了，如果确实有特殊需求，可以私信找童思扬说明理由

申请。
