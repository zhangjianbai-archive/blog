李菊英信件

李菊英你好！

王聪颖的事情。我认为还是要跟你说一下。

我认为你们还欠我一个说法。从10岁开始我就出力出钱替你养女儿，给了很多的机会去培养她，给她别人都没有的各种机会。长到20多岁你们家长都没有操过多少心。

她作为弟子，最基本的条件是【承担师门责任，捍卫师门荣誉】。但最终，你们一家都不珍惜我给的机会，她的带班效果连新手都不如。我相信这不是她能力不够，而是心不在带班上面。她不想带就算了，没人逼她。想去外面走走也很正常。但你们走的时候，连招呼都不给我打一个，心中有一点起码的感恩心，有一点敬师的样子吗？

她人小，不懂事，也就算了，可以说是怪我没教好。但你一个大人，作为家长，也一句话没有。是不是有点不够意思？还是我做了啥对不起你们的事情？

当然，今天找你，也不是要找你们算账。这世上不懂事的人多了，我也没空去一一算账。算账没啥意义。只是我从小看王聪颖长大，一直对她有好感，不忍心看她越滑越远。她如果将来人生失败，沉沦不起，对谁都不是好事。我也不喜欢将来让别人拿她的人生失败来笑话你们和我们。倒不是我怕笑话，今日新教育，大概只需要再过三五年，奥运冠军就会到手。这时候，名满天下，谁想黑我们都没门的。但你们这些本来可以获得最大尊重的第一批学生，如果混得不好，恐怕就成为大家都想挖出来的笑话了。

我也不愿意看到我曾经看好的小女孩因为一时短见识，导致一生的穷途末路，不想看你们这样混日子！你这母亲，虽然也缺脑子，没见过大世面。你也只有小聪明，不懂大趋势。我看你也帮不了她太多忙，指导不了她的人生道路。但我相信你也不愿意看她从此慢慢沦落下去，抱憾终身。

因为我的判断是预后不良——王聪颖正在走向一条你们不愿意接受结果的道路！

首先说明：我虽然过去培养了她，但也没指望你们家知恩图报。没有要求你们一定要为我做事。能为新教育做事，是个人的福报，有些人没有这个福报，就不必勉强。

你们想离开圈子，去圈外发展，做自己想做的事情，过自己想过的生活，我也一样支持。只是希望你们出去以后，能够活好一些，活得更成功一点。别活成了别人的笑话！

但我看到王聪颖给某个人的信，却很担心你们迷失了方向。担心王聪颖这样跟着瞎混下去，会越来越失落的。会跟你们离开圈子以为拥有了美好的未来的愿望相反。所以我特别提醒你们注意自己的选择！

王聪颖的信，是劝说某人皈依到寂如师傅这里的。她自己反复强调：说在师傅这里感觉很好，师父很慈悲，她感觉很好等等。我相信王聪颖是真心话。也相信在王聪颖在学堂里面，因为自己不用心，导致教学和人际关系失败，因此在自己的心理低谷期需要安慰和鼓励。她去寂如师傅这里，得到了她非常需要的关心和帮助和支持，也是一件好事。

但如果你们希望王聪颖将来活得更成功一些，更开心一些，我不得不提醒你注意思考以下问题，用理性。而不是用感情来思考问题。就算是我最后提醒你们一次吧！听不听，都在你们了！

思考一：你们家认为，王聪颖离开她熟悉的，自己已经有十几年来积累的人脉和影响力的圈子，她拥有各种先发优势的地方发展不好。难道她去一个对她完全陌生，她积累几乎就是零的圈外发展，一切从头开始，难道她就会更成功吗？她有什么特别的又是，让她在外面的世界更成功？更受拥戴？更有地位？

这个社会很现实的。你想得到的一切，都必须拿你自己实实在在地拥有的资源来交换。你的职业，婚姻，家庭，社会地位等等，都必须跟你的个人能量相匹配。都不仅仅要拼个人的才华和努力，也要拼自己的资源和能力。王聪颖想要过自己想要的生活，回到外面的主流社会，她打算付出什么?得到什么？成功的可能性有多大？希望你们好好想想。

思考二：她跟随寂如师，是要出家跟随师父修行吗？如果她不是为了成佛（我没看出她有佛心，寂如师傅身边的一堆人，我看都跟寂如师的发心就不一样），如果你家王聪颖，只是为了找个让自己更舒服的新圈子，想要躺平混日子的话，倒是没有问题。只是如果她还有一点追求，想要获得世俗的成功。寂如师傅的修行圈子，对她的婚姻和事业，以及生活的发展空间，你们认为会比别的圈子，比如新教育和体制内的圈子更大，更好，更有前途吗？如果不是，她会不会再一次浪费自己的生命？让她将来的人生道路越走越狭路？你们难道需要再拿5年，10年的时间去体验一条不成功的道路，然后再次的荒废掉，将来再重新选择新的道路吗？你们有多少个十年可以混下去？

黄崇睿6年前，因为带班有问题，其实认真地学习和改变就好。就像侯晓燕和钟老师一样。但黄老师却不肯面对和改变自己的不良习气，也不接受同伴对她带班的批评和建议，不去认真学习新教育，不想改变自己的积习，就负气辞职，离开今日去拥抱世界了。但她也非常的不适应世俗的生活，也不愿意去城市里面踏实的做一份普通的工作，就业。而是到处去寻找心灵安慰，也找个逃避和偷懒的地方，后来就跑去跟寂如师这里混了6年。今年5月我去佛山，她来见我，我直接说她：没见她跟学了六年有啥变化。很遗憾发现她并没有去学到寂如师的东西。就像当初跟我几年，也没有去学到我的东西一样。到哪里都是混日子。现在她去了【某先生学堂】，觉得很对她的心意。本质上还是不肯跟主流社会同步。但她离开我们之后，找了一个比我们更大，更有发展空间的平台？还是一个更小，发展空间更有限的平台？这样下去，她会不会将来不仅仅事业没有，最终婚姻也没有？正常的生活也没有，这一生就是到处漂迫，打混？

你们女儿应该不想成为这样的案例吧？

另外，跟寂如师时间更久的一个人，杨帆。当年今日学堂起步的时候，她就在跟著在外围的学堂一起混了。当年她刚刚从大学里面研究生毕业没多久，是一个心高气傲的才女。当年还是大方学堂的台柱子。后来她瞧不起大方，自己辞职离开。但我这里她也进不来，就自己去外面到处闯天下，她也试图自办学堂，但因为虽然人聪明，但很不踏实，她也不好好学学真教育，导致本来她拥有很好的发展机会，却最终失败。去大理呆了几年，又去办民宿，最终也失败。她陆陆续续也跟寂如师父学习，现在算算时间，已经接近20年了。但我看到她的路，却越走越狭，一晃她已经40多岁了，一直是恨嫁心切，她也一直在寻寻觅觅自己的理想伴侣，却一直没有机会成家。

她到现在还在玩青春期游戏。但原来很多很好的机会，却因为她不珍惜而失去了。很多原来是支持她的人脉，现在都远离她了。我这里原来也欣赏她的她的才华，她也来找过我。原来我还跟她提醒两句，帮帮她指指路。后来看她的越来越不成器，我的话也听不进去。我后来也不想浪费时间，看她不受教，只是找我废话，我就直接拉黑她账户了。但其实她并没有做啥对不起我的事情，我只是不愿意继续浪费时间去陪她说废话罢了。如果我连一句话都不愿多说给她！我相信她周围的人脉，都会被她这样浪费掉了，导致她虽然年龄越大，越没机会！无论是生活，事业，婚姻都这样！因为她的心智就没有成长。

四年前，我见到寂如师，说起这两个我们原来都很熟悉的人：我表示很佩服寂如师父的耐心。我根本就教不了的人，我都受不了的学生，他还愿意耐心的带领她们这么多年，明明她们就是在混日子，也一直不把她们赶走，也不怕浪费时间。他知道我的意思，但也只是苦笑。说他没办法，佛家讲慈悲，学生能学多少就算多少了！不像道家讲缘分，缘分不合，就不再结缘了。她们只要想跟着混，他也尽量教。不求结果！

我说这两个人的故事，就是提醒你们：也许她们的未来，就是你家王聪颖的未来。王聪颖还没有她们豁得出去，社会上还没有她们油滑。更糟糕的是：王聪颖还没有体制内认可的学历和文凭，将来，她模仿这两个人的话，只会比这两个人混的更惨。这也是难说的！

就比如一件很简单的事情：婚姻大事！如果王聪颖在新教育圈子里面。因为她的清一弟子身份，大家也不在乎她的文凭等等。她的婆家，也不会认为她学历不够档次，也会获得婆家的尊重！

但如果她离开我们这个圈子，圈外人看她，就是一个没有身份地位的人。就算是男方看中她的素质，但家世只要是好一点的婆家，就一定会看不起她的。会让儿子离她远一点。换个有前途的女孩家。除非这家的儿子独立性很强，很有主见，非她不娶。

因此：如果王聪颖在我们圈子里面，她拥有如此良好的个人婚恋条件，都找不到你们家合意的对象（虽让你们家这么挑剔的呢？超级不现实的追求）。但你们怎么可能期待——她离开圈子，就会找到条件更好的工作，找到档次更高的婆家呢？

难道，王聪颖去寂如师父的圈子，就能解决她的婚姻和事业问题吗？别以为去个大城市就容易找对象了。起码黄和杨二小姐，就一直嫁不出去的！

说这些并非劝说你们“回心转意”，而是提醒你：应该选择什么样的道路！不要跟著感觉走。但时候啥感觉都不灵的。

如果你在乎女儿的婚姻，以及未来的事业和发展，你们就应该抓紧时间，趁她年龄还不大，赶快去上一所还不错的大学。某些国家第一流的大学，会自动选出够档次的，上进和负责的男生女生。她如果放弃我们圈子的人脉，你就要帮她选择比我们更好，起码更多，更大的圈子，比如正统传统社会的大圈子。要抓紧时间，帮她谋取一个正当的身份和地位。不然——-她将来会活得高不成，低不就，最终啥都不成，抱憾终身的！

据说王聪颖已经放下了自己原来对男方的高傲和挑剔，正在跟一个比她原来可以选择的对象条件差很多的年轻人谈恋爱。一个原来学堂毕业的男生。我无意干扰你们的好事，最终这件事情你们如何评估我不知道。但我知道这个前学生，自己的事业也不靠谱。他自己是在这个社会的边缘地带打混的。他还没有融入更大的圈子，也没有拥有自己的领地。也许他最终会获得自己的地位吧。但最终结果如何，真的难以预料。假如王聪颖真的跟他结婚生子，她们就是过个普通人的生活，就在边缘上打转转，日子过得下去也就算了。

但万一她们两的这段感情失败，王聪颖将来还能重新站起来吗？她怎样重新站起来？请你们好好思考这个问题吧！

你们现在急于去拿到的东西，也许并不是你真正更想要的东西。王聪颖现在年龄也不大，现在很多女孩快30岁了也不急于嫁人，很多人还在忙与工作，甚至读研究生。她现在需要这么忙把自己嫁出去干嘛？早生贵子吗？现在不赶快趁年轻，为自己的身份地位打点基础，将来嫁人，也没有地位？自己的事业追求更是啥不靠谱。去当全职太太吗？自己还咋活呢？

因此，我建议王聪颖收拾起自己的玩心，不要任性。要严肃认真地面对自己的选择和命运，不要拿什么东西都开玩笑。既然你们离开了我们圈子，你们就要努力为自己打拼一个更好的天下，去找到自己在世界上的位置。而不是现在就无所事事，去跟一些没事干的人一样，去寂如师这里想过退休生活。

她现在最重要的事情，就是必须抓紧时间，去上个好一点的大学。比如去考个日本的好大学，或者东南亚的一流大学都行，毕业之后自己的选择就要大很多。你们就别去白种人的大学了，没有啥现实意义的。以她的才华，考上一个亚洲的好大学很容易，让她耐心好好的去读几年书，为自己充实一点经历，学点真本事，拥有一个正当的身份和地位，也不至于让未来的婆家瞧不起。要做事业，也有一份底气。也许她在大学里面，她还可以遇到她真正想嫁的人。至少她去大学，有更多的机会思考自己的人生，可以明白自己想要什么。而不是现在这样任性，耍小孩子气，躲在家里找妈妈安慰。把一副好牌居然打的稀烂。

她既然不服从我们的安排和指导，就应该彻底地为自己负责，该沉下来好好去上大学，去提升自己的实力。是我认为她目前最应该做的事情，而不是到处去找男人，赶快嫁掉自己。或者假装修行。玩虚无体验。（恐怕现在的男生，现在还未必想赶快娶她，也许你们只是想玩玩感情游戏？但现在你们恐怕真没这个实力来浪费你们的生命）。而且王聪颖去上大学，想要跟男生继续保持关系，也是没有问题的！只是实在犯不着一棵树上吊死自己！

新教育正在快速的起飞，5年后，一旦我们的奥运战略实现，必将轰动全世界。将来也必定鱼龙混杂，成为未来的名利场。将来，凡是跟我们有点关系的人，恐怕未来都是到处被人抢的资源。你们却在这个时候，自己主动宣布退出圈子，挺像是1949年宣布公开退党一样。不知道你们的眼力是怎样的犀利！现在，王聪颖丢弃不要的职位，马上就有五个新人竞争职位。跟王聪颖入职的时候几乎没啥人跟她竞争完全不同了！将来我们的职位，只会越来越热门的。

你们家庭看不起新教育没关系。否定自己的过去没有关系。但你们最好找到更好的东家再丢弃。我的建议，就是让王聪颖去找到更好的前程和路径。去为自己的下半生努力建立基础。得到更好的发展。别指望有人会眼巴巴的送你上青云，你们自己该努力的时候，就一定不要偷懒去玩情调了。你们离开我们的照顾，就只能自己更加努力，更加精进，不然只能在社会底层，边缘沉浮了！希望你们好运，找到你们想要的未来！

另外，我对你们还有一个建议：王聪颖从10岁就开始建立的缘分，是很多人一辈子都得不到的机会，是非常难得的机遇。你们把这种经历当成垃圾，说丢就丢，我没有意见。但你们也要学会“骑马找马”。你们对我们玩绝情，是跟你们自己的未来绝情，是断你们自己的后路。你们还不至于笨到这点都不知道吧？做人留一线，日后好相见。因此，大家都留个念想。王聪颖喜欢抱怨，但希望学会不要做怨妇。日常多累计一点口德。就怕万一新教育真的崛起了，就怕将来你们在外面发展不顺利，又需要回头，不要弄到回头无法见人的地步。人走错路没关系，谁都会犯错。只是不要固执地认为自己不会犯错误！随时保持谦恭的态度，对帮助过自己的人持感恩的态度，人生才会吉祥如意。

最后，有三件事情，说明一下！

一：当年你生老二的时候，我跟你说过：将来孩子上学，我可以帮忙你安排入学。今年10月，已经为钱莉的孩子安排开班了。比当年小明慧的班级条件好得多。本来你们的孩子可以上这个班的，但你们一直没有申请。如果你们看不起新教育，想要走正途，当然也就算了。如果你们还需要入学帮助的话，可以找我。我原来的承诺依然有效，可以帮你们办理入学的。

二：今年开始，我的家族基金办公室开始启动。用于帮助一些有志气的穷人家庭，让他们也有机会获得更好的精英教育和学习机会。如果王聪颖将来上亚洲地区的大学，你们家庭有经济上的困难，你们还是可以找我申请的！

三：据说你们想要退掉原来定的磨丁社区房。这是一笔小钱，如果你们确定自己家庭，将来再也不愿意与新教育结缘，当然退掉社区房，是一个正确的选择，我无意强留你们。只是我想提醒你们一句——马上社区房就开始分房了。明年三月，今日学堂就正式进驻磨丁了（现在明珠班已经先期进入了）。将来我们在磨丁，会开展周末讲堂等活动，必将成为新教育的核心区域。也许，你们需要为自己的未来可能的需要，留一点合适的缘分。没必要现在王聪颖离职了，就弄得像是仇人一样永世不再相见，把一切本来可以帮助你们家的善缘，助缘，都不加分别地断个精光吧？我们不会排斥你们，当然我们也没工夫陪你们玩你们的游戏。但你们也没必要排斥我们，自设墙壁吧？

还有一件事情：当年你在学堂基金会的时候，用你的账户在香港投资，记得数额并不太多。后来你离开学堂之后，我曾经要求你把资金转回来。但你说你把香港的银行卡丢失了，疫情期间没法重新办理，所以一直就耽误下来了。现在，基金会的事情，已经交给付向东和应佩瑶。她们负责担任学堂的对外校长，也负责管理我们学堂的香港账户和基金。希望你把这个原来留下来的尾巴事情，找机会了结掉。大家更加自由的地过你们的想要的生活。我已经告诉了付向东，他应该会与你联系这个事情的。

祝你们全家安好

张清一
