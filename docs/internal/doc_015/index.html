2022年道家⽣命科学、慧⼼⿊关静⼼营“预报名”启动

课程重点说明：

（1）道家⽣命科学、慧⼼⿊关静⼼营是针对慧⼼⽔⼿们的福利课程，⽼师

以师带徒模式授课。参与者均在辟⾕状态下完成，这⾥所说的辟⾕并

⾮单纯的断⻝，⽽是古传道家辟⾕术的传授，请知悉。

（2）报名对象：仅限⾄少推荐过1位慧⼼初阶学员的家⼈（该名额可以是

使⽤过，也可以是新的）有资格申请道家⽣命科学、慧⼼⿊关静⼼

营。

（3）上课条件：道家⽣命科学课程、慧⼼⿊关静⼼营的参习者，第⼀：需

要具备处理⽣活关系的能⼒，因此，⾄少参加过1次【初阶复训】。

——满⾜此条件者可以报名；



第⼆，需要具备⼀定的智性，上过⼭⻓的【⼼理⾏为课程】。



同时满⾜两个条件者，会优先录取。

（4）报名费⽤：道家⽣命科学、慧⼼⿊关静⼼营费⽤均为2.1万元。每推

荐⼀个慧⼼初阶名额抵5000元学费。

道家⽣命科学课程（原慧⼼中阶4个课程）：

说明：考虑到慧友们时间宝贵，参加完整个中阶课程耗时太⻓，将原四个

年级的课程浓缩成⼀⻔新课【道家⽣命科学课程】。





1.

报名条件：限23岁以上，70岁以下⼈⼠参与。

2.

时间：共9天。

3.

费⽤：2.1万元，推荐⼀个慧⼼初阶名额抵5000元学费（⻝宿费⽤全

免）。

4.

上课地点：云南，具体位置待定

5.

上课时间：此课程预计会与2022年下半年在国内开课，具体未定。

6.

报名原则：以先报、先审、先通过、先排班的原则进⾏！

7.

报名流程：

第⼀步：填写报名表（请勿修改报名表格式）



第⼆步：发送⾄hxgzf@188.com邮箱。邮件名称：姓名+道家⽣命科

学课程。



邮件具体内容：1）报名表；2）⼿持身份证照⽚；3）如果您参加过

⼭⻓21⽇课程，请您同时发送“清⼼课”或“⼼理⾏为调整”的班级群的截图

（包含：班级群名称、我的本群昵称）➕上课录取邮件截图，届时我们会

核实班级信息。

慧⼼⾼阶课程：⿊关课程——静⼼训练营

说明：慧⼼⾼阶⿊关课程改为收费制，并保留原有推荐制模式。具体情况

如下。

1.

课程内容：该营旨在启动内在光明⾃性，开启⼤智慧。

2.

报名条件：限20岁以上，65岁以下⼈⼠参与。

3.

课程为9天。

4.

费⽤：2.1万元，推荐⼀个慧⼼初阶名额抵5000元学费。（仅限未使⽤

名额）。

报名原则：以先报、先审、先通过、先排班的原则进⾏！

报名流程：

具体内容：1）报名表；2）⼿持身份证照⽚；3）如果您参加过⼭⻓21⽇课

关于⻝宿费⽤说明：



a、因基⾦会所建设的⿊关楼尚未完⼯，开课时若课程需要借助第三

⽅，⻝宿费⽤第三⽅收取，学员需要⾃⾏承担；



b、若⿊关楼完⼯投⼊使⽤，则包⻝宿费⽤。

温馨提示：

慧⼼⿊关静⼼营需要⽼师在场任教，⽬前因疫情原因，⽼师⽆法回国，同

学们也⽆法出国。因此只接受“预报名”。时间地点未定，请知悉。

⼆、关于慧⼼推荐名额及课程的说明

1，截⽌到2022.2.26晚24:00，关于已完成同年度推荐10个名额的慧友（所

荐学员已经参加完初阶课程的学习），您将会获得清⼀基⾦会颁发的【慧

⼼四星学员】荣誉称号，您已经是慧友⼼中的榜样，您的照⽚将作为【慧

⼼之星】挂在清迈慧⼼楼，供后来者学习。

您的名额可兑换如下项⽬（四选⼀）：

1）可⽤3个名额，邀请亲友免费参加慧⼼初阶。

2）可⽤3个名额，免费参与⼭⻓的7⽇财富课程（此福利仅限慧⼼之星）。

3）⽤于抵扣道家⽣命课程的学费；

4）⽤于抵扣⿊关静⼼营课程的学费。

【慧⼼四星学员】名单稍后会在群内公布。

温馨提示：清⼀基⾦会将于每年的2⽉份推出【慧⼼之星】荣誉榜单，评选

⽅式除了【推荐荣誉榜】之外，还将增设【特殊贡献】榜单，将重点考察

做义⼯次数等内容。

2，名额仅限⾃⼰使⽤，不再接受转让。

3，抵过费⽤的名额，均不可再次使⽤。

4，学友可根据喜好任意选择：道家⽣命科学课程&慧⼼⾼阶课程。

5，名额时效性均为两年，过期不⽤就作废了。

6，中⾼阶课程将不再⽤排列的⽅式解决家族关系等问题，对此问题还需要

解决的⼈，请上初阶复训。

因此，建议您参加初阶复训，处理好家庭关系，提升⼼灵层次之后再来参

加，效果显著。
