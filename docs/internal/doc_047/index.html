婚恋课程报名须知20210425

婚恋心理行为学课程报名须知

一、报名对象：

18岁以上的单身，有求偶需求的单身男女对象来参与。（参考报名年龄男生：18-33周岁；女生：18-30周岁）婚恋心理行为学课程不是普通的知识类课程。所以，已婚者禁入，就算是“想离婚的人”也禁入。

二、课程简介：

婚恋心理行为学上课内容，包括约会指导，男女交流沟通的指导等等内容。当然，也包括男女之间的心理和行为的不同，心理解析的内容，价值超高。

婚恋心理行为学特别课程，还给大家送额外的一个全课程的机会（21天课程，免费额外加送21天，总共给42天课程）。送出来的就是山长真金白银送的培训，不是简单的“优惠打折”。这样做，是因为男女，夫妻关系，是人伦中最重要的事情。我们提供的，不仅仅是一个课程，也是提供了我们清粉圈的交友平台，交友机会，是利用山长的影响力，把大家聚合在一起。给大家更多的时间，用于互相熟悉，沟通，交流，甚至开始谈恋爱的。所以，希望有机会来参加的人，都珍惜这个课程的价值。这种课，不会经常开的，几年才会开一次。希望大家把握机会。

补充说明：婚恋课已经送了21天的课程。不再送财富心理行为课。

三、课程时间：

2021年6月11日-7月22日（课程时间21天，赠送21天，合计42天）

四、课程地点：云南昆明

五、授课方式：

由于疫情防控原因，山长暂不回国。山长是通过大屏幕视频连线给大家上课（与我们的教师内部培训一样），但是我们会有助教在现场为大家服务。

六、报名流程：

1、需要由【婚恋心理行为预备群】群友推荐才能报名；这个群的人是经过山长的线上课程，写了作业入群的人，更加理解婚恋课的含义。需要在申请表中注明：推荐人编号（如：H0001 或 D0001）+推荐人姓名。其他人员推荐无效。

2、填写【2021婚恋心理行为学】申请表、按照申请表内容填写并手持身份证拍照。

3、由推荐人发申请者资料（申请表及身份证照片）到公务邮箱：academy@188.com

4、报名工作组进行审核，审核后会发出录取通知邮件。

5、推荐人收到录取通知邮件后按通知交费并发截图到公务邮箱。

6、交费成功后申请入班级QQ群。

7、报名满员即止，会及时在【婚恋心理行为预备群】发出通知，在报名工作组发出截止通知后再申请者属无效报名。
