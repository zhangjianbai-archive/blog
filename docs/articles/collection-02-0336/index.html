山长一直宣传的，15岁考SAT1500，到底有用吗？

聪颖·教学与成绩

文章总览

档案馆根据原文整理

  • 聪颖质疑用SAT高分宣传常春藤出路，指出大学申请还需要其他课程成绩、推荐信和课外经历。 查看原文：一、SAT高分≠申请藤校
  • 她讲述一名高分学生离开冠军班、转向国际学校的经历，批评把自主选择升学道路解释成背叛。 查看原文：六、不去冠军班，行吗？

有用，非常有用！

前提是，15岁的你，带着这样的SAT成绩，去申请进入一所国际学校（很可能可以拿到全奖），然后学习AP课程，通过AP成绩+这所国际学校的背书、推荐信，可以申请顶尖的大学，如常春藤盟校。

但是，

如果15岁考出成绩后，就自以为已经“藤校在握”了，想着去冠军班学习“高级智慧”。

三年后、18岁的时候，你只会发现自己一无所有。

不止申不到藤校，连世界前200的绝大部分普通学校都无法入读。

进入冠军班——武夺不了冠军，文也上不了藤校。

一、SAT高分≠申请藤校

这一点，在嘲笑鸟的文章中已经非常清晰的阐明了。

一句话总结：SAT成绩并不能评估学术水平，还需要AP等成绩、有分量的推荐信、有效的课外活动。这些都是冠军班无法提供的。冠军班最理想情况能打出的泰拳成绩，对于申请藤校，也没有什么价值。

如果你或者你的孩子，未来要做这样的选择，建议好好看看相关的文章。抛开立场，只是看文章的事实。

如果有的家长觉得，我们所有写文的人都是在“刻意抹黑”，可以随便去找留学中介问问，验证是否属实。不要相信山长所说“留学中介都是骗人的说法”。相比于成功送出无数留学生的中介，至今一个藤校学生也没有的山长明显更不可信。

再如果你还是没时间去问中介，也不愿意信我，没有关系，可以看看今日的学姐（三语高中第一届毕业生）怎么说：

https://zhuanlan.zhihu.com/p/27836269704

考AP、ALEVEL课程，一般需要2年时间（但更多新教育的学生案例，普遍2年是完不成的，因为他们的理科基础太弱）。我听说的最快的一个案例，是一年时间考出，这位同学是之前在体制学到高中后才进入新教育的，数学基础非常好，还线上找了机构指导，花了十几万。其他的同学甚至有花费更多的，几十万的都屡见不鲜。

而山长口中的“三个月给你一堆AP”，我不知道有谁做到过，希望山长给出个真实案例。如果能三个月做到，我也很疑惑，为什么上面这位同学不去三个月搞定AP？一下就能申到好很多的大学了。如果没有案例论证，山长这句吹牛的大话，拿给留学圈的学生看，都是要让人笑掉大牙的存在。

二、SAT成绩≠申请大学

如果只是不能申请藤校，也还可以接受，毕竟这个世界上还有很多好大学可以上。

更可怕的现实是，仅凭SAT成绩，不管是1400还是1500，都几乎无法【申请大学】（这里只考虑QS200以内为范围，更靠后的水校就不谈了）。

因为绝大部分大学，都要求高中学历和成绩单，这是无法替代的硬性标准。

少数学校能够接受职高学历，但是在入学考量上，也可能会减分。

几年前，今日在玉溪的比欧三语高中，还能给学生提供职高学历。但是只发了一届的学历后，学校就关门了，第二届没有学历。第一届学生中如果毕业后晚两年申请大学，也会面临“母校”关门这样的尴尬情况。

现在，今日的学生完全没有高中文凭，绝大部分学校根本无法申请。

山长知乎曾经点赞过的日本SGU项目，即拿英文成绩申请入学日本大学的英文项目，不需要学日文。

https://www.zhihu.com/question/642800086/answer/49353816329

这里的十多所日本顶尖大学中，只有两所，是可以用职高学历申请的。

如果没有普高也没有职高学历，这里所有学校都无法申请。

马来西亚前五名的公立大学，加上马来西亚莫纳什等前几名的私立大学分校。

其中第一名的马来亚大学要求高考成绩，新教育学生直接无法申请。有几名新教育学生早几年去入读了，因为当时疫情，大学申请门槛降低。现在已经不行了。

私立第一名的莫纳什马来分校，职高学历可以申请，但是会被各种质疑，最终很难通过。

其他多所大学中，除了2所可以拿GED申请（还不能确定是否就能申请通过），其他至少要求职高学历。

山长大力鼓吹的GED，所谓一个月就能考出来。的确没错，因为这个GED根本没用啊。

https://zhuanlan.zhihu.com/p/14188533226

不看学生真实案例，只会妄想瞎编的“蠢猪”、“黑猪”，不知道是谁呢？

当然，还有一种大学，教学质量很好，不要求高中学历，在家自学都可以申请，那就是美国大学。

美国30名以内的，没有AP成绩基本不可能申请到。但是30名以外、尤其是50名以外，是有机会的（申请网站上有这个选项，能不能申到就不知道了。有高中成绩还是会明显有帮助）。

不过，山长一直说去美国留学是智商税，如果你听了他的话，就把这几乎唯一的路也给断了。

现实是，同样QS排名的大学，美国学校的教学质量往往远远更高。比如澳洲的墨尔本大学、悉尼大学，世界排名13和18，而耶鲁大学和普林斯顿大学，排名22和23。孰优孰劣，一眼便知。

当然，去美国的确有很大的障碍，就是费用。四年本科学费+生活费大概要200万。近期因为特朗普的各种操作，更带来了额外的风险。 所以，如果去美国留学是你无法选择的一条路，那么，没有高中文凭，你在世界前200大学里，就只剩下个位数的选择了。

三、世界前200的大学，含金量如何？

按上面的分析，如果你想办法解决高中学历，或者哪怕有个职高学历，还是很有机会入读世界前200大学的。

问题是，世界前200大学，到底是怎样的含金量？真的像山长所说，相当于中国C9吗？

我们来看看新教育中很多人去往的马来西亚，在留学市场上，很多被认为是中国考不上大学的学生才去的。其中第一名的马来亚大学，要求中国学生提供高考成绩，要求的分数是：

2024/2025第二学期(25春季)高考成绩要求暂未调整，依然是470分

2025/2026第一学期(25秋季)中国学生要求高考成绩分数线最低520分

重磅！马来亚大学录取门槛又又又提高了，高考分数竟然这么高！

而考上中国C9需要多少分呢？以江苏省为例，最低的西安交通大学（世界排名295名）文科要求627分。

这两个大学，含金量真的一样吗？

在校园招聘市场上，世界前200，大体相当于中国211；世界前100，大体相当于中国985。有部分企业对QS100大学更看重一点，但是远没有达到中国C9的水平。

四、SAT成绩有效期

如果你通过各种渠道，搞定了高中文凭；或者去申请那仅有的几所不要求高中文凭的学校。18岁，你依然会面临一个挑战：

SAT成绩，不是终身的，它只有两年的有效期。

15岁考出的成绩，如果2年内不用于申请大学，就作废了，18岁只能重新考试。

如果15岁考出成绩后，就再也不大量使用英文了，到18岁再考出当年的成绩，需要花费大量的时间精力重复投入。如果15岁的时候通过应试技巧等方法短期冲刺到高分，那18岁重考的难度只会更加提高。

五、学日语有用吗？

冠军班仅剩的一点学习时间，山长还没有让他们去学习对未来大学有用的科目，而是让他们学日语。学日语有用吗？

很多学生多次问山长为什么学日语，只能得到这样两个非常牵强的理由：

中国文化很多传到了日本，要学中国文化，就要学日语；

日本老龄化，就业机会多，所以要学日语。

第一个理由非常扯，山长自己也没学日语呀，也从来没说过清一大学研究生要学日语。

第二个理由就更加自相矛盾了。当年山长鼓吹三语道路，专门告诉大家，不要想着学法语德语日语，去发达国家享福，而要学西语，去发展中国家，借助中国一带一路的机会，进入中资跨国企业工作。

现在怎么就要学日语去日本工作了呢？

日本是不是有很多就业机会，我们不清楚，但是，我们学生也不是去做便利店店员的，日本的高端就业机会，到底有多少？我们作为外国人，能竞争到多少呢？

以及最直接的，学日语，能否考日本大学？

答案是，几乎不能。

如果想通过日语来考日本大学，需要参加EJU留学考试。这个考试的内容和难度大体如下：

文科考试范围如下，

日语（总分450分，400分选择题+50分作文题）

数学（总分200分，出题内容：初中+高一知识）

文综（总分200分，出题内容：经济、社会、历史、地理、政治知识）

理科考试范围如下，

日语（总分450分，400分选择题+50分作文题）

数学（总分200分，高三+少部分大一知识）

理科（总分200分，物理、化学、生物，三选二即可）

数学试卷分文理两部分，理科数学难度大于文科数学。目前数学科目的难度逐年增加。大有与国内高考齐平的趋势。

目前国公立大学基本全部采用该考试，私立大学中也有接近一半的大学采用该考试成绩作为参考。

相反，不学日语，能否考日本大学？

答案是，可以。

上面提到的SGU项目，不要求日语，只要有SAT+雅思成绩，加上高中成绩单，就可以申请。

与其学日语，不如用这个时间巩固下英文，以及让家长想办法弄到高中学历。你能申请的大学要多的多。

六、不去冠军班，行吗？

你说，如果我在今日考到1500分，然后不去冠军班，会怎样呢？

你的前途是一片光明。

唯一的一点：你曾经非常信任的老师，会把你踩在地上，告诉所有人：

你堕落了、青春期了、没有理想了，你居然想去考大学，居然向往外面的世界，而不想去冠军班。

你得在新教育圈、今日圈社死，作为离开的代价，也作为杀鸡儆猴的牺牲品。

这是去年发生的真实故事，一名1550+的优秀学生，只是因为想要去考大学，自己研究发现走冠军班路线走不通，决定离开，结果被痛骂，被张清一引导让所有学生与TA对立。TA用了很长时间走出低谷，最终全奖进入了一所国际学校，目前成绩优异，前途光明。

你拿到1500了吗？你接下来，要选哪种人生？

这里的一切，以最善意的猜想去推测，是山长不清楚细节，抓大放小，没有研究升学的具体路径。

那么作为今日宣传的重要特色，作为新教育体系最顶尖学生的出路，校长和老师不去研究清楚是否可行，对得起学生吗？

在这么多人发声，提醒这条路不可行之后，山长有去承认吗？有去修改宣传语吗？还是去把所有发声的人打成“清黑”，禁止人们在群里传播他们的文章，连让更多人看到的机会都没有？

甚至，在事情已经这么明显的情况下，内部老师还在忽悠学生，用这种想当然的幻想去解释：

（第一次见到说，一个人要展示自己的运动水平，是去跟招生官比划两下，笑死）

这一切，真的能用只是疏忽来解释吗？还是山长想要建独立王国，刻意把学生留在体系内，故意让他们错过能够走向社会的机会？

我知道，有些身在冠军班的同学会说，我很感恩山长教我的，哪怕上不了大学我也不后悔，我不许你黑山长。

你喜欢是你的事。

可是，如果山长编造谎言，让更多想要上大学的学生，以为进入冠军班可以通往更好的大学之路；让更多想要走向社会的孩子和家长，因为这样的幻梦而进入新教育。

那这样的老师，值得你尊崇吗？这样的谎言，值得你捍卫吗？

如果山长明明白白说，我这个班就是练武和学习高级智慧，不想上大学的才能来。

那么今天也不会有这么多所谓清黑在积极的发文。

因为所有这些更内部的人，经历了更多的人，看过太多美好的幻梦，最终发现只是谎言。

世界名校，如果只是封闭王国，何谈世界？

如果世界名校都是假的，那山长谈的一切，还有什么值得相信呢？

还是说，他让我们大家都相信了，唯独不信的，是他自己？
