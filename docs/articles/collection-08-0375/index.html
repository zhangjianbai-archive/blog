老而不死是为贼——以教育之名行毁人之实的贼

黄传科·权威与控制

作者：黄传科

老而不死是为贼”，孔子两千多年前的怒斥，并非对年长者的泛泛诅咒，而是对那些年岁徒增、德性却逆向狂奔道貌岸然之人的精准鞭挞。

此言在今日读来，尤显振聋发聩，尤其当我们这几个月目睹某些披着“教育家”外衣，实则以岁月积累的威望为资本，行误人子弟、敛财控心之实的老头时，更觉此语堪称一面照妖镜。

其贼一，贼在窃取学子之前程

教育者，传道授业解惑也。

一名真正的教育者，其生命价值应由其培养的人才来衡量。

若一人从事教育二十余载，美其名曰“精英教育”、“传承国学”，门下却无一人成材，反将学生变为“无学历、无能力、无工作”的“三无人员”，此非教育，实为屠宰。

他屠戮的是青年最宝贵的求知欲与可能性，窃取的是他们本应光明灿烂的人生前程。

时间，在他这里成了最讽刺的帮凶——漫长的从业年限并未沉淀出智慧，反而精进了其蛊惑人心的骗术。

其贼二，贼在玷污学问之神圣

国学与传统文化，本是民族智慧的瑰宝，却成了他进行精神洗脑、打造个人宗教的华丽袈裟。

他将知识异化为教条，将尊师扭曲为盲从，将一群寻求真理的学生与家长，驯化为不容置疑的“信徒”。

这绝非发扬文化，而是对文化最彻底的背叛。

其所作所为，不仅未能“为往圣继绝学”，反而让真正的国学蒙尘，让社会对传统文化教育产生疑虑，其行可诛，其心可鄙。

其贼三，贼在消耗社会之信任

年长者，本应因其丰富的阅历而更显慈悲、包容与睿智。

然而，当面对如山铁证的指控，他非但无一丝反思，反而动用最后的影响力，裹挟在读学生与家长，对年轻的揭露者发动网络暴力。

这是一种极其恶劣的“毒魅”：以老资历为盾牌，以受害者（学生家长）为武器，将一池清水搅浑，试图将一场关于真理与错误的辩论，扭曲为一场“以下犯上”的尊卑之战。

他消耗的是社会对“老师”这一身份的最后信任，其行径，堪称“贼”之狡黠与无耻的极致。

贼之老，非年岁之过，乃德性之殇

“老而不死是为贼”，我们批判的从来不是衰老本身，而是那些在岁月长河中非但没有修炼出澄澈的灵魂，反而将沧桑变为算计、将威望化为枷锁的人。

他的“不死”，于社会无益，于青年是灾。

既然地球容不下你了，那赶紧走吧。

真正的长者，如明灯，照亮后辈之路；而此等“老贼”，如迷雾，困锁青年于深渊。

当教育沦为生意，当学生变为信徒，当反思被网暴取代，他已不配称为教育家，只是一个寄生在教育光环上的“贼”。

在本该退休养老，颐养天年，含饴弄孙的年纪，出来跟二十多岁的老师，学生在网上骂战，你好意思不？

未来是属于年轻人的时代，你算算还有多少年跟这些年轻人耗？

时间，从不自动赋予任何人尊严。唯有德行，才能让白发成为智慧的象征，而非罪恶的遮羞布。
