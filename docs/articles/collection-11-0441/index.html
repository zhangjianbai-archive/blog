清一山长是谁--新浪博客考古

Klein·权威与控制

作者：Klein

引子：

1. 新浪博客的关闭

自2022年起，新浪博客的博文都被系统自动设为私密，站在游客的角度看这些页面就是冷冰冰的四个字——“暂无博文”。

目前新浪博客打开已经提示：系统维护中，仅作者可见，登陆后查看本人文章。

教主的多数博文已无法考证

由于教主的博客正文当前不可公开查看，早年被广泛转述的“出格言论”无法通过原帖直接考证。

2. 逆天言论的出现

近几个月有文章（现已被教主投诉下架）的评论出现今日学生宣称“教主从来没有说过今日的学生要上常青藤”的说法，实在是可笑，不过由于学业繁忙，本人当时并不想花浪费时间在打嘴炮上面。

不过自8月底开始，教主逐渐滥用知乎的举报机制，把那些与自己意见相左的文章全部以“「涉嫌侵犯个人的权益」”的理由举报下架，清粉圈逐渐提纯，过几个月照样无事发生，往日的文章流逝在时间里，

这让我突然想到《1984》的一句话——谁控制了过去，谁就控制了未来，

因此，本来只是在各个文章评论区发言的我，决定公开发文，为“思想启蒙”贡献自己的一份力。

互联网档案馆（Internet Archive）

1. 介绍

互联网档案馆"（Internet Archive）是1996年成立的非营利组织维护的网站，目的是建立一个数字化的全球互联网图书馆，以保留互联网上的文化遗产，使其能够被后代访问和研究。

就像纸质图书馆一样，为研究人员、历史学家、学者、阅读障碍者和公众提供免费访问。使命是提供所有知识的普遍获取。

从 1996 年开始对互联网本身进行归档，当时互联网的使用刚刚开始增长。

现在保存内容有：

7350 亿个网页

4100 万册书籍和文本

1470万 录音（包括240,000场现场音乐会）

840 万个视频（包括 240 万个电视新闻节目）

440 万张图像

890,000 个软件程序

2. 功能

时光机：用户可以输入一个网址，然后选择特定日期，以查看在那一天的网页样貌

网页保存：互联网档案馆定期抓取互联网上的网页，将其存档以备将来查看。

多媒体资源：除了网页，互联网档案馆还保存了许多其他类型的数字内容，如音频、视频、图像等。

文献馆藏：互联网档案馆包含了数百万份数字化的书籍、期刊、音乐和影片等文献。

研究资源：研究人员可以使用互联网档案馆的内容进行学术研究，了解互联网发展的历史，也可以访问以前的网络内容以进行比较研究。

免费访问：大部分互联网档案馆的内容都是免费提供的，任何人都可以访问。

本文是通过“时光机”访问新浪博客以下架的教主博文，从而寻证教主的各种承诺。

3. 使用小贴士

并非教主的所有博文都能被收录，建议通过多方资料详细考证（如前几年流传的教主博客文集pdf）

有些文章因为影响力较小，存活时间较短，Internet Archive并未收录（如聪颖、卓蓝、爱党爱国爱人民的文章）

访问该网站需要“科学上网”

4. 使用方法

1、复制你想要查找的网址，比如“教主”的新浪博客（可以用搜索引擎找到）

2、打开Internet Archive，将教主的网址链接粘贴到搜索框中，选择“Search archived web sites”

然后按“Go”就行啦，这个以防清粉看不懂特意题型一下^^

3、选择“Calendar”，将时间轴调整至至少“2017年”，因为教主的博文最晚只更新到2017年（为啥必须要选Calendar捏？因为作者也是刚接触，只会用这个……）

点击标蓝的日期

4. 成功访问博文！

到了这一步，你就已经成功了一大半了！

博文首页

点击“博文目录”，可以访问所有历史文章，

由于历史文章有关“教主”的称谓太多，我就不把截屏放出来了 : (

5. 失败

还有一种情况就是，Internet Archive并未收录该文章。

大概的意思是：这个网页无法存档，因为网页不存在
