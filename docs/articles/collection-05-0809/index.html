对第一性原理的思考

张乘风·教学与成绩

文章总览

档案馆根据原文整理

  • 他用系统论等模型对照课程中的概念，主张先弄清原理，而非把换一种说法当成独有智慧。 查看原文：对第一性原理的思考

我认为新教育最缺的训练就是“第一性原理”，而后者理工科的思维就很关键。文中的三种课：4类性格色彩、对人生的态度、还有换个视角看事物，其实都有类似的数学原理或模型。性格色彩分类，这个压根不是个严肃的学术训练，根本不适合当课程使用，即便是定义的精细和准确度压根比不上五行理论以及荣格大师的MBTI人格分类。五行理论的生克关系理论完美对应系统论和控制论，如相生关系对应系统正反馈，相克关系负反馈，人体五行平衡就类似于系统的周期迭代下的超稳态。感兴趣的朋友可参考金观涛的超稳定系统相关理论。如果你了解过这个，再看性格色彩理论，只会觉得很幼稚。而对同一个人，换一个视角得出“成功”or"失败”的不同结论。这个在数学上能找到的原理不要太多：最简单的，线性代数，坐标系变换后的向量变化；决策模型里的效用函数，效用函数变化会导致效用值完全不同。至于老张以及钟老师的案例展示不就是贝叶斯定律么？一个先验的主观判断，根据事实的调整改变最终的概率值，多个不同性质的事件导致最终概率值剧烈波动。老张天天挂在嘴边的智慧，其实说透了也就是这点东西。体制内的优等生也许会被这些说辞糊的一愣一愣的，但你要知道这绝不是人家笨，而是人在年轻的时候大脑擅长演绎推理，而年纪大了大脑会更擅长整合归纳。今日系的学生认为：这是一个充满智慧的平台。对这种共识，我不得不说一句：井底之蛙。反过来说，今日系的学生不学数理化，看似不用卷了，但其实也错失了很多思维上的训练和积累。以学生最“怕”的数学为例，真正数学学得好的学生，对数学不是排斥，而是一种探索中的乐趣。乘风中学时是数学竞赛选手，印象很深的一次体验：高中时自学微积分，有一天看到导数时，居然自己推导出了一堆公式，觉得很好玩，后面发现居然是后面积分和不定积分的内容，有一种“我tm原来是天才”的感觉。那种一个年轻人沉浸探索又洋洋自得的感觉，至今都记得。当然，乘风压根不是天才（虽然也是省级一等奖选手），数学是终极智商检测器，会很快的告诉你：你的天赋在哪一级，比你低一级的你觉得人家是傻x，比你强的大神们，看你感觉是一样的。而知识之间是有贯通性，数学-物理/化学-社会-经济-历史-生物-中医-修行，这条链走下来，那种探索和体悟的乐趣，和人类文明同频对话的乐趣，学渣是绝对体会不到的。新教育这么多优秀的苗子，早早就放弃数理化，我只能表示遗憾了——“你们根本不知道自己错过了什么”，人类群星闪耀时。实际上，我非常怀疑张清一的体制优等生身份，所谓“平时不学习就很容易拿高分”。因为，张清一对数学的态度明显很排斥，甚至说出“数学只需要小学内容就够了”。而80年代的大学生，口号是“学好数理化走遍天下”，优等生几乎没有数学不好的。实际上我还真看过80年代的数理化教材，难度大但可读性明显更好，大学扩招后教材难度是逐年下降。张清一如果是优等生，怎么可能这么排斥数学？或者说，他是个不错的学生，但离平时不学习成绩就很好还差得很远。但不管怎么样，现在的今日学堂学生的文章已经能说明很多问题了。如果我来评价，只能说：知识和见识层面上，达到了张清一的标准——老张自称“不学无术”。心智上，两个字：幼稚。分享三堂我以前非常喜欢的课：五行人格、山长双重身份、心态觉察课
