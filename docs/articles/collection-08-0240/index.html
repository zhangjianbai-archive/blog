新教育就是一个草台班子

黄传科·权威与控制

作者：黄传科

新教育里面所有人的唯唯诺诺，自卑，自我否定，失去理性，变得极端，都源于把新教育想得太强大了，太完美了，却没有洞察到他们那里的空虚，假话连篇，一旦你洞察到这种空虚，一切在你眼里就是纸老虎。

根本不存在值得你仰视的人和物，你也根本没必要觉得自己一无是处。

即便你一无所有，你依然可以昂起头，挺起腰杆，潇潇洒洒做人。

有些人面对真相选择沉默远离，有些人选择匿名回复，说出当时的真相，这些我都理解，面对网爆每个人心理承受能力是不一样的。

当某些人实名说出真相的人，遭到各种谩骂攻击的时候，沉默也就成了大多数人的选择。

但我依然鼓励你们匿名发声，或者转给我们这些不怕网爆的人。

张刘夫妇不过是一个草台班子，一个装神，一个弄鬼。

一个自喻为张三丰，王阳明的转世，要打造中国的文化上层，建立世界名校，扒开内部一看惨不忍睹，所谓的世界名校不过是红灯区的一栋公寓，基金会形同虚设，变成为个人谋利的名头而已，数十年来，只知道画饼，一个接一个，却从不实现承诺，说话经常矛盾重重，以点带面，以偏概全。

一个只不过学过一点家排，偏门的玄学，就可以看透疾病的真相，为何自己的亲人，学堂的老师都出现很严重的问题。

所谓的2.0老师也是一个草台班子，里面充满了大量的混子，师生恋，混乱的男女关系，比比皆是，里面没有专业人才，课程设置单一简单，老师全都是内部繁殖的，没有经过社会验证，以及各种考核的小孩，经过这一次网上舆论的发酵，全都露馅了，就这居然是收费不菲的精英学校。

他们之所以成为神，都是你给加的滤镜。

台湾作家李敖娶了大美女胡茵梦，没几个月都离婚了，理由就是美女也会便秘，李敖接受不了这个事实，

离近了看，哪有什么神，都是凡夫俗子。

所谓的清粉群也是一个草台班子，

大家本来都是老实本分的普通人，一个个却硬要做精英，培养精英，没有做精英的命，却一个个都患上了做精英的病。

实际上在教主的洗脑下，还会用孝道，感恩等糟粕文化给你洗脑。

让你自己觉得永远欠别人的，好像就不该来到这个世上，各种把自己贬低到尘埃里。

当你看透了世界是草台班子的本质，就可以大大松一口气，没有什么配不配，敢不敢的，只要是机会，你就争取，只要你认准了哪一条路，就勇敢去走，没人能把你怎么样。

该上台就上台，该吹牛就吹牛，该装逼就装逼，该撕逼就撕逼，怎么活得开心，你就怎么活，哪里有那么多瞻前顾后，小心翼翼，都是草台班子，谁配笑话谁呀。

在力所能及的情况下，多体验，多感受，看看世界的大好河山，感受世界人情冷暖，读读好书，看看电影，把自己的工作生活和家人打理好，能够在自己的生活中感受平静安宁，就已经是非常棒的一生了。

很多清粉说你反对清一教育，那你把孩子送到

王聪颖那里去吧，祝你跟我们有相反的结果等等之类的。

我看了就想笑，

我反对张清一的教育，并不代表我支持王聪颖的教育，我不了解她的教育方式和理念，但是我支持她说话的权力，只要有道理我都支持。

这些清粉也只会用诅咒大法和套用张教主的语言来回答问题，完全没有自己的思想和逻辑。

从来没有一种教育像清一教育这样，前家长跟教主撕逼，前师傅跟教主撕逼，前弟子跟教主撕逼，前员工以及学生跟教主撕逼，教育成果看不见，多年来只盛产清黑，这也算是教育界的一种奇观了。

而且每隔几年都会爆发一次，最近爆发的这一次提前了，而且持续的时间特别长，到现在还没看到结束的迹象。

在这里预测下一次粉黑大战大概在什么时候爆发。

我估计是在2028年吧，参加奥运会可没有那么容易，没有专业的教练和后续保障团队，估计连奥运会的门槛都进不了。

到时候我们看教主如何消化这个自己曾经画下的国礼大饼。

我现在看起来其实这个世界挺好玩的，我甚至有点想支持新教育了，

但并不是因其理念而支持新教育，纯粹是他们为我们这个稍稍显得枯燥的世界，创造了那么一点点欢乐，可以一直吃瓜。

就像我支持川普一样，并不是我赞同其政治理念，纯粹是川普比拜登让我们可以吃到更多的瓜。

老张各种骚操作的表演，对人心的拿捏玩弄，真的是精彩，他的存在可以一直让我们有瓜可以吃。

如果要选择一种教育方式的话，我宁愿自己教，父母才是孩子的希望，新教育不是，孩子也不是父母的希望。
