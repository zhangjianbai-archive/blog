山长是道家老庄的2000年清静无为派的代表，现在的清黑们是“欲望派”。【利用师生信任，先把立场锚定，而且2000年的历史纷争、地球能量场扬升等宏大叙事，非常对理想主义的学生味口】第二，欲望派历史上经常获胜，但最终祸国殃民。【解释学生内心疑惑：为什么这次清黑的力量这么大，人数这么多？消除学生对失败的恐惧：同时要有悲壮失败的准备，正义失败是常事。】第三，要实现理想，要防止被洗脑，一定要注意魔的力量。【你心里是不是动摇了？动摇就对了！这是魔的力量引诱你，动摇你，因为你的修行力量不够！】第四, 不要管关注和别人的对比，也不要关注我失去了什么，往前看。【不要在意你的上届师兄师姐的出路，也不要在意你后续的升学求职会怎么样，往更远的方向看（时间上扩展到2000年），更宏大（空间上扩展到地球宇宙），你一个小小学生的个人得失算什么？】第五，做高级的人，还是低级的人，自己选。【你要成为魔、还是很low的只顾自己利益（升学方向）的人？还是光明的、有千年传承的道家门派传人，在未来地球能量场变化中幸存下来，你自己选。】【恐吓：如果你选择错误，那是你自己的责任，别怪我山长没提醒你!】走到这一步，除非学生具备的极强的心力，即【“犯错也没关系，我也有办法站起来”】这种成年人中都不多见的心力，大部分的学生只会选择跟随山长，而今日系日常对学生无休止的打压（比如至上），【群体内的风气都不敢犯错的】，最终几乎所有的学生都会无视历史惨痛的案例和新教育圈好心人的提醒，选择所谓的“清净派”。事实是，张健柏是道门中最欺师灭祖的弟子（如果他真的认自己是道门中人），刘存所用，恰恰是控制人心的邪术。张健柏目前面临的，就是天谴！一个很简单的、几乎很难有分歧的话题——“山长所说的五大出路是否合理”——就这样，在张健柏的玄学操控下，所有学生都不再关注了。【因为关注，就是低级能量、只关注自己的小人、欲望派、被魔控制心智】逻辑上，老张这套说辞永远不会被打败。【人家失败了2000年都认了，你能说啥】可笑的是，如果是道家传人，会这么容易怕被外界的舆论影响吗？今日系的学生，你们内心真的连1%的顾虑都没有么？你们的批判性精神在山长面前，都失效了么？你们真的觉得，一个学生，去研究、践行的自己的毕业出路，是很低级不耻的么？老子有言：“天道无亲，恒与善人”。什么是善人？“善者善之，不善者亦善之，得善也”——世界上不存在“粉”和“黑”之分，亦不存在“清净”和“欲望”之别，没有哪个立场能够真正代表你，天道无亲。
