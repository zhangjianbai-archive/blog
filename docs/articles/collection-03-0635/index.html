讲出我所了解的今日学堂之事实

作者：烟雨入诗画江南（施畅）

作者很尊重我们的隐私，没有暗示或者明示更没有“唆使”我们来签名。但是我想来做一个实名者。

简单说一下我的履历:我是施畅。从2012年8岁进入学堂，17岁入职今日塾，担任2021届突破班助教一年，今日示范班主班老师两年至结业。

去年秋天当我决定不再做管理班的指导并从今日辞职的时候，虽然对于学堂的一些方面也有不认可，但同时也觉得从小到大学堂确实带给了我很多的帮助和成长，曾经朝夕相处的老师和同学也依然在内部工作，所以不想在舆论方面有太多介入，也不希望去进一步破坏这些私人关系。另外自己马上也要进入大学，也有很多相关准备事务，新教育已经逐渐从我的生活淡出。

然而，近期在网上看到的闹剧着实让自己觉得非常乍舌，为什么很多内部之前的伙伴和清粉会以正义凌然的姿态掩耳盗铃，作出一些明显虚假且过激的表达来维护平台的“形象”。这些行为似乎与我们小时候在学堂受到的教导截然相反，于是我决定在这里简洁地陈述一下自己的观点。

首先，前段时间关于聪颖、黄校和孙师傅的私人恩怨，还有诸多争议点例如基金会的资金纷争、武术流派等，尽管自己在学堂的时间有12年多，但是我依然认为对于这些事情和领域的了解是不够充分的，也并非亲历者，不能完全确认很多细节的真假，因此我无法妄作判断和评论。不过，有一件事情自己是可以确定的:尽管从众多反馈来看无可否认刘JH校长对于一些学生而言帮助很大，但同样存在的事实是她对包括我在内的多名三语高中女生进行人身攻击，评价为是“心机婊”及相关具有明显贬低甚至污蔑性质的描述,并且传播至男生班或其他教师。

只能说，她在部分情况下展现出的友善和美德可能是基于特定前提的。

另外一个过去一年以来我一直都想说但没有勇气直接说的事情是:冠军班宣传的常春藤目标可行性约等于零。

常春藤不同于此前的外语突破，冠军奖牌，K12和SAT等项目，它既不能自定义标准，也因内卷程度极为剧烈不能依靠“蓝海捷径”通关。眼下冠军班自认为很天才的申请路径既不小众，也严重缺乏竞争力。学生18岁毕业后将会面临不仅无法考入常春藤盟校，也会因没有高中成绩单而无法进入各国其他优质大学的现实。而目前全体教师、学生和家长好像都乐于披上这件“皇帝的新衣”，我无法理解这样做对于其中任何一方究竟有什么长远的好处。也希望冠军班的学生不要用自己的青春去追逐海市蜃楼，或者至少清晰结果后再去追求。

看到这些“清黑言论”也许会让你感到惊讶，但是这种情况下就是我爸常说的“两方说法直接矛盾，必然至少有一方在说谎”。究竟什么是真相，什么是谎言?相信时间会给出答案，因为潮水总有退去的时候。“清粉”和“清黑”本身就是两个荒谬的概念，重要的或许根本不是立场，而是事情到底是怎么样的。

如果接下来需要开始“爆料”我的小故事，歪曲历史，可能是“为情所困”、“为人不善”等等，我也丝毫不会感到意外。退一万步说哪怕我是一个品德极差居心叵测的人，仍然不会改变任何既定事实。
