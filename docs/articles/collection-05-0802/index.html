我们要站在第一性原理思考问题，不要被张清一的道德绑架

张乘风·权威与控制

文章总览

档案馆根据原文整理

  • 他指出，张清一一方也在使用实名举报，质疑其一边谴责举报、一边用举报压制异议的双重标准。 查看原文：我们要站在第一性原理思考问题，不要被张清一的道德绑架

张清一利益团伙对清醒们的道德指责，往往是维护正义最有效的、最正当的的手段，大家一定不要被迷惑！

张清一团伙指责清醒们匿名，而实名就会被张和泼妇带头网暴，聪颖、卓蓝、施畅、孙师父、前家长学生……匿名反而是清醒们最好的自我保护方式！而少数勇敢正义的老师们公开实名站出来作证，我们要做的就是保护好她们！不要被匿名的道德绑架，网暴一方连涉黄分子都敢出来实名装纯情，我方匿名有法可依，有理可据!

张清一团伙指责清醒们举报，而他自己却上传身份证以实名的方式举报张乘云的刑侦分析文，清醒们不举报只会让清粉的垃圾信息堆砌网络、网暴他人的威慑久久长存，因此，我们要大胆举报、理直气壮地举报，把这些污染正常讨论的噪音压到最低！

张清一团伙指责清醒们拉黑，而他的舆论打手们几乎没有不控评拉黑的，我们听了他的标准，只会让小太阳、觉清这种刷屏分子把评论区搞得乌烟瘴气，连正常地讨论都做不了！因此，拉黑的手段，我们要果断用，对小太阳、觉清这种评论区要发几十条垃圾回复的，不仅自己拉黑，还要广而告之，理直气壮！但是和张清一不同的是，我们允许评论区有合理、礼貌的质疑，是不是用心在交流，那是很清楚的。假装理中客实则搅浑水，最后被拉黑喊冤，那就让他喊冤去吧，我们没有义务对他的真实动机做精准的判断。

张清一团伙指责清醒们要搞垮今日，而他自己对异议者开办学堂极度敏感，从2012年的李姓教师到今年的王聪颖，几乎都要除之而后快！我倒是好奇，谁给了张清一这种理所当然地“正统心态”？你办的学校丑闻频出、罪恶滔天，你的亲信害死孩子、逼疯学生，你本人更是侵吞公益资金，甚至有一堆大瓜还没爆出来，到底什么是国礼计划，你敢正大光明讲清楚吗？今日系这种烂到底的地方，不垮天理难容！你以为清醒们写文章揭发你，难道是要请客吃饭，祝你越搞越大？不打垮藏污纳垢的今日，新教育行业怎能完成净化升级？天道如此，因果不虚，休怪他人！

张清一团伙指责清醒们不够尊师，而他对孙师父怎么做的？你不承认是孙师父弟子，那派这么多学生过去学功夫是何居心？又要学人家的秘传功夫，又觉得当弟子委屈，哪有这种好事？中国人尊师是因为重道，而师一旦有违天道，则必被剥夺师的地位。因此，清醒们要明白，对邪师一旦认清，要立即划清界限，把他从心中“老师”的位置踢出去，批驳邪师不必有任何道德枷锁！

总之，张清一团伙一旦站在道德层面对清醒们指责，清醒们要知道，老张很可能被搞痛了，不要被他的话语所迷惑。打蛇要打七寸！
