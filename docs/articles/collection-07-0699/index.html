作者：守其黑

知其白，守其黑。

在“新教育”这场漫长的纷争中，我们是否曾静下来想过一个最基本的问题：

我们的“敌人”，究竟是如何诞生的？

他们曾是我们的同学、我们的老师、我们的家长，是我们曾一度信任和尊敬的伙伴。然而，一夜之间，他们就变成了面目可憎的“清黑”、“汉奸”、“疯狗”、“活在地狱里的灵魂”。

这并非一次自然的决裂，这是一场被精心策划和导演的“敌人制造工程”。而这场工程最讽刺、也最悲哀的地方在于，它盗用了我们都曾深信不疑的、《与神对话》

的最高智慧，来作为其最核心的理论蓝图。

今天，我们就来拆解这座“敌人”诞生的工厂，看看它是如何背叛“神”的教诲，来制造“魔鬼”的。

第一重背叛：用“分裂”的行动，对抗“合一”的真理

“神”的智慧：

《与神对话》给予我们的最高真理是“我们都是一体的”（We Are All One）。在神的眼中，没有分裂，没有“我们”和“他们”。每一个灵魂的旅程，都是神圣而完美的。

他们的“应用”：

然而，这个体系却用这份“合一”的智慧，制造了最深刻的“分裂”。他们构建了一个泾渭分明的二元世界：

“清粉” vs “清黑”

“上层” vs “底层”

“清净派” vs “欲望派”

“光明” vs “黑暗”

“天堂” vs “地狱”

这是一种最根本的背叛。他们口中谈论着“合一”，行动上却在不遗余力地制造“敌人”。

他们将所有与自己意见不同的人，从“我们”这个神圣的整体中，无情地切割出去，并贴上一个邪恶的标签。

他们不是在践行“合一”，他们是在用“合一”的优越感，来享受“分裂”所带来的权力。

第二重背叛：用“审判”的权力，对抗“不评判”的慈悲

“神”的智慧：

神在《与神对话》中说，就连“希特勒也去了天堂”，因为在神的国度里，没有审判，只有体验。最高的智慧，是去“观察”，而非“评判”。

他们的“应用”：

然而，这个体系却构建了最严密的“道德与人格审判系统”。他们化身为全知的心理医生和法官，对所有“敌人”的灵魂深处，进行公开的、不容上诉的“最终判决”：

你的批评，不是因为你看到了事实，而是因为你“天赋差，跟不上节奏”。

你的反抗，不是因为你受到了伤害，而是因为你“想嫁的人娶了别人”。

你的质疑，不是因为你追求真理，而是因为你“活在地狱里”，被“‘怕’的诱发思维”所控制。

他们用一本教人“不评判”的书，去进行最严厉的“评判”。

他们将自己置于了比“神”更高的位置，去裁决他人的灵魂状态。

这并非智慧，这是最极致的傲慢。

他们不是在分享神的慈悲，他们是在盗用神的名义，来行使人的审判权。

第三重背叛：用“偶像”的崇拜，对抗“我是神”的赋能

“神”的智慧：

《与神对话》最伟大的赋能，是告诉我们：“真理在你之内”，“你，就是神”。它旨在打破所有外在权威，让我们回归自己内心的神性。

他们的“应用”：

然而，他们对这份智慧的应用，最终都指向了同一个结论：我们应该去相信一个新的、至高无上的外在权威——山长。

他们用“神说……”，来论证“山长是对的”。

他们用“神不评判”，来论证“山长不应被评判”。

他们用“神说爱”，来论证“我们应该无条件地爱山长”。

这是最令人叹息的讽刺。他们将一本伟大的“个人独立宣言”，降级为了一本为新的“个人崇拜”服务的“效忠手册”。

他们用书中的每一个字，去构建了一个与这本书的精神完全相反的、充满恐惧、分裂和偶像崇拜的王国。

动机，为何“敌人”是必需品？

那么，他们为何要如此系统性地、不遗余力地制造“敌人”？

因为“敌人”的存在，是这个高控制体系赖以生存的“燃料”。制造二元对立，是其实现绝对控制的最有效手段：

控制身份：通过定义一个邪恶的“他们”，来塑造一个高尚的“我们”。这赋予了追随者强烈的、精英化的身份认同和归属感。

控制信息：一旦“敌人”被确立，所有来自他们的信息，都可以被轻易地定义为“谎言”和“负能量”，从而实现完美的信息过滤，构建一个坚不可摧的“思想茧房”。

控制情感：对“敌人”的共同仇恨，是比“爱”更强大的、更具煽动性的情感粘合剂。它能轻易地激发群体的战斗热情，将所有人的情绪都调动和统一起来。

控制行动：一场永不结束的“战争”，为领袖的所有极端行为提供了“合理性”，并要求所有成员必须时刻保持“战斗”姿态，从而将他们的全部生命力，都消耗在这场被精心编排的斗争之中。

结论：

所以，亲爱的朋友，请看清这个真相：

“敌人”不是天然存在的，它是被制造出来的。

而制造这场战争，其最终目的只有一个：通过树立一个共同的外部敌人，来掩盖所有内部的矛盾，并巩固领袖不容置疑的绝对权威。

在这场被精心编排的战争中，没有真正的赢家。唯一的“燃料”，就是我们每一个人的愤怒、恐惧、忠诚与希望。

醒来吧。拒绝扮演你被分配的角色，拒绝使用那些充满分裂的标签，拒绝参与这场以“神”之名，行“魔”之事的战争。
