作者：爱党爱国爱人民

我们完全认可国家社会主义核心价值观！我们爱党爱国爱人民！我们人人有责建设现代化富强社会主义国家！为共同营造法治社会，坚决捍卫社会主义之下的人民权利，现将中国体制教育之外，不被教育部认可，已逃往至海外的“新教育”，对涉嫌违反中国人民法律的地方进行举报。

我们不能容忍中国法治系统下，非法办学的教学不规范对未成年人的身心伤害。现正式向有关部门提出举报：

1、依据《未成年人保护法》第62条立案调查

2. 依法处置涉事教师及包庇人员

3. 取缔该机构办学资质

致所有关心新教育的家庭、今日学堂管理者及教育主管部门：

我们是一群曾在今日学堂就读的学生和家长。今天，我们决定共同发布这封公开信，详细陈述一系列发生在我们身边的、令人深感不安的事件。我们深知，揭开旧日伤痕需要巨大的勇气，但为了避免更多孩子可能面临的风险，为了推动教育环境的真正透明与安全，我们别无选择。

此信无意于私人报复，而是基于多位当事人和目击者的共同记忆，对一个教育机构系统性风险的公开质询，以及对所有家庭的郑重提醒。

一、 缘起：一个令人费解的任命

故事始于2014年。今日学堂在马桑果中毒事件后，迁至四川罗江校区后，时年17周岁（其身份证出生日期为1998年11月，实际出生于1997年9月）的刘姓教师，在学堂创始人张校长的亲自推举下，与多位名校毕业的成年教师竞争上岗，并最终被任命为“天二班”的班主任，从此开始全权负责一群13-14岁青春期男生的教学、生活与“心性成长”。

我们的第一个质询，直指师生恋存在的土壤： 是什么教育理念，会让该机构张校长相信，一个正值青春期的17岁女老师，有足够的能力和成熟度去引导另一群同样在青春期的13-14岁男孩教学？此举涉嫌违反《教师法》第11条教师资格规定。

在学校做出这一任命时，学校是否设置了任何有效的监督和制衡机制，以防止因年龄、阅历和权力的错位而产生的两\性关系风\险？

二、 第一个案例：对学生小U的“特\殊调整”

刘某独立掌管天健二班后，很快便对班内一名13岁的男生小U（化名）启动了学堂特有的“闭关”训练。小U被安排独居在校区后院，与集体生活隔离。刘某作为闭关师对小U进行单独辅导，为后续的不正\当关系创造了条\件。以此为背景，一系列由多位同学共同目\睹的、超越正常师生界\限的场景开始频繁上演：

不恰当的身体接\触： 在班级集体活动（如玩桌游）时，小U会自然地戳刘某的腰腹部，而刘某非但不制止，反而以拍打作为回应，两人互动亲昵，在旁观学生眼中“极像情侣”。

充满意味不明的表达：小U经常用iPad和刘某亲昵聊天，刘某把自己“理想丈夫”的文章链接发给了小U，并附言：“加油，要努力”。小U回复：“好的，爱你”。然后两个人互相比心。

模糊的私人空间界限（多名男学生）： 多位同学证实，刘某经常允许男生进入她的房间，甚至坐在她的床上一起煮东西吃。更有甚者，她曾以“自己阴气重”为由，召集其挑选的几名优秀男生（飞跃小组）到她房间，坐在她床上，帮她“提升阳气”。

深夜的单独相处： 有同学在凌晨1-2点，目击刘某身着清凉（如超短裤）在房间外与小U单独聊天。在昆明活动期间，两人看电影时会选择远离大部队的最后一排，并在深夜一同走在队伍的末尾。

假期中的两人独处：次年夏令营结束后，小U没有放假回家，一直跟随刘某身边。据刘某说是在给他做特殊调整。当时就可以看出小U对刘某的依赖性很强。张校长当时对此的解释是：刘某和母鸡一样，把男生当儿子去保护。

这一系列行为，让当时的学生们感到困惑与不适。而作为当时年仅13岁的小U，在经历了这段“特殊调整”后，对刘某产生了极强的依\赖。我们看到他的床头贴满了“为了爱你，我愿意赴汤蹈火”之类的便利贴。当刘某因被调离教学岗位而与他疏远时，小U陷入了巨大的痛苦，严重心理危机。甚至严重的自can行为，并最终因心理问题被学堂要求退学。回家后给家庭带来了巨大的痛\苦。相关证据已依法提交给相关部门。

我们在此质询：

上述由多名学生交叉证实的行为，是否符合一位“老师”应有的职业规范？所谓的“提升阳气”等说辞，是否是一种利用学生们的信任与无知，进行不当影响的手段？

当小U出现明显的情\感依赖和极\端行为时，学堂的管理层是否进行了有效干预？还是对此视而不见，最终以将受伤害的孩子“开除”了事？

三、 第二个案例：师生恋升级，与学生小Z的“同居”疑云

时间来到2016年春季学期。刘某重返教学岗位后，另一名14岁的学生小Z（化名）超越了师生界限的关系。据多位同学回忆，当时班级严格禁用手机，唯独小Z被允许持有，理由是“家里有事，老师批准”。

此后，更惊人的情况发生了。在长达两个月以上的时间里，小Z的同宿舍同学发现，小Z经常深夜一两点才回来，每周至少一两次整夜不回。有同学在深夜不止一次看到小Z跑向刘某所居住的教师宿舍楼，或从那栋楼的方向回来。（补充说明：刘某居住的楼仅有两间教室和两间教师宿舍，分别是刘某和另一位成年已\婚女教师居住。学生并无理由前往）

很久以后，当事人小Z自述：刘某很会利用教师权威实施不当影响。她的方法是先在班级内建立小范围飞跃小组，选出还不错且愿意服从和配合她的人。之后她会经常带小组在房间内做单独活动。再往后开始一对一互动。一对一互动有时候在外面，有时候在房间。晚上灯光昏暗，坐在她的床上，氛围暧昧，在密闭空间进行超越师生界限的身体接触。这些肢体接触让人感觉非常触\DIAN。理智在氛围下非常薄弱，小Z和刘某存在涉嫌违反《未成年人保护法》第42条（禁止与未成年人发生不正当关系）的行为”。“根据《刑法》原则，教师与14-16周岁学生发生关系可能涉嫌犯罪”

然而纸里包不住火，刘某一直到同居，都拒绝和其他男学生承认和小Z的恋\AI关系，因此小Z与刘某发生争吵深夜跑出，被同住一栋楼的song某发现而败露。song某随后调取了监控录像，录像内容证实了小Z深\夜PING繁出入刘某房间的事实。为慎重起见，song某还邀请了另一位资深女教师qian某共同查看，并拷贝了录像发送给张校长。(我们不能确定当前的局势下两位学堂老师是否会出来提供不实陈述。但我们作为学生有权利说出当时的真相)

然而，面对如此确凿的证据，张校长的处理方式，令我们至今无法理解：

真相被掩盖，涉事教师安然无事： 刘某被迅速要求离开学堂，但对所有师生的官方解释是“因不愿练武，不符合弟子身份而被逐出”，清一书院学生都知晓。然而，10个月以后，2017年4月，刘某回归重回教师岗，未有任何官方说明。

受害者被淘汰： 当事学生小Z，被直接取消了升入高中部的资格，学期结束后即被淘汰。

证据被封存，相关知情人被打压： 关键的监控录像，从此下落不明。数位相关知情人被明面和暗地各种方式打压和排挤，大多离开了今日。

我们必须向张校长提出最严肃的质询：

面对如此严重的师德败坏事件，为何处理方式不是公开通报、引以为戒，而是将涉事双方“悄然清除”？

为何师德败坏的刘某，依然能安然在今日系继续教学？并担任无X学校的校长？

四、 师生恋后续：延绵不绝、愈演愈烈

刘校长多次师生恋远远不止以上两例，刘某女士回归后也并未停止她重复性失范行为。

2021年，刘某担任三语高中男生班指导老师时期，据悉依然出现了和男生集TI\单REN夜里单DU夜WAN聊天；在酒店与男生班在小池子穿着清\凉泡温泉（高中女生班发现并拍下照片）；与男同学夜\里私会被时任高中校长黄XY发现并上报；与男生班H、L、Y、Z等四位同学产生过情gan关系和纠ge，导致当中学生出现抑yu和情gan障碍。

近期，张校长已在公开平台宣布刘某与她曾教导的一名高中男生（两人年龄相差七岁）订婚，而该男生也是在法定结婚年龄之前就被目睹和刘某同居。

“我们并非要干涉成年人的婚恋自由。但我们必须提出一个关乎公共利益的疑问：一个教育机构，如果反复出现教师与自己所教的、心智尚未成熟的学生发展亲\MI关系，它所传递的情感观，究竟是健康的，还是不健康的？

当学堂创始人张先生，对刘某女士的这类行为持续纵容时，我们不禁要问：您亲手制定的教育原则，是否在您最核心的圈子内就已失效？这是否意味着所谓的‘新教育’，最终还是凌驾于规则之上的‘人治’？”

我们的最终呼吁：

我们以事实为据，以疑问为笔，写下这封长信。我们恳请：

今日系的张校长，能停止在私人感情问题上打转，正面回应上述所有质询，向所有曾经和现在的学生、家长，以及社会公众，作出一个负责任的交代。

所有新教育家长，在为孩子选择教育路径时，请务必擦亮双眼，审慎考察任何机构的师资背景、监管透明度及学生保护机制，切勿被美好的理念蒙蔽。

教育监管部门，能对这类长期游离于主流监管体系之外的“新式私塾”或“书院”进行彻底的、深入的调查与规范，确保师德底线不被突破，确保每一个孩子的安全与尊严不被侵犯。

我们已准备好，将我们所掌握的所有证据与证人线索，提交给任何有公信力的调查机构。

沉默是对错误的纵容，透明是走向安全的第一步。

（一群今日学堂前学生前家长 联合发布）
