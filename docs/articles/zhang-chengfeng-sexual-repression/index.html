继续侃老张的情史

老张出生于1963年，吹嘘自己40岁以后选择很多，大致就2003年以后，恰好他在武大成名期间，那时候老张身边确实有很多20岁漂亮又单身的女大学生，老张当打之年自然春心萌动。

于是，老张开始疯狂追求一个武大校花，被人家父亲知道，当面怒斥老张“癞蛤蟆想吃天鹅肉”，于是老张经常自嘲“有这么帅的癞蛤蟆吗？”，他这20多年就反复讲“武大校花生活不如意”。

多说一句，老张这辈子和父亲关系一直不咋地，当年落魄时创业实在钱找爹借还被拒了，他爹一直看不上这个儿子，他对别人家的父亲（武大校花、小孔这类学生）的敌意天然就很强。父为乾，乾为天，天道这门学问老张一直学得不咋地。

但老张身边莺莺燕燕确实不少，他和几位女学生的关系也确实进了微妙的暧昧期，这时候武大风言风言自然多起来，加上团委对张的打压，老张就把老实巴交的穷学生尹某推出来，网上写文反向造谣说团委污蔑自己和尹某有染。

当年互联网还是比较单纯的，这事出来没人再怀疑老张搞女学生了，只是坑了尹某，丢了学籍，除了去今日学堂，没别的路走。对了，尹某自幼被奶奶辛苦拉扯大，她的爹也是失位的。反正欺负没爹的娃，或者欺负娃的爹是老张的传统操作了。

但代价是，老张把自己架在道德高地上，再去找女大学生当老婆就有舆论压力了，毕竟师生恋想想可以，现实要背负舆论压力的。于是老张找了三十多岁，看着年龄偏小的神婆。算是一种代偿。

但这种代偿是有时效性的，老张50岁以后（2013年以后），神婆也40多了，老张博文里的两性关系话题突然增多，特别是有一篇痛斥40岁律师睡了19岁女孩的文章，这律师居然把细节写到了网上。老男人搞定年轻女人总是有心理成就感的，这不奇怪，但这事情最多说这律师小人得志，说道德不堪都有些勉强——谁规定大叔不能睡小女生的？老张一个搞教育没事攻击别人私事干嘛？

心理学上，攻击=链接，强烈攻击往往代表与攻击对象的连接渴望，这里最合理的解释就是老张嫉妒了，忍不了了。神婆这时也老了，没年轻时有活力了，老张的欲望又来了。

更要命的是，精足不思淫，反过来讲思淫必然精不足。什么叫精不足？给你们看老张现在的照片，猥琐气短。

颅内高潮期

到2025年，老张已经60多岁了，正式进入了颅内高潮期。

这个时期的特点就是精气神不足后，五阴炽盛难以压制，加上NPD的心理渴求本身大于常人，这就导致，老张的精神世界一直紧绷着。

这时候如果和神婆关系身心都和谐，老张是能获得心理平静的。可显然不是，真正恩爱的老年人是充满祥和和平静的，而不是阴阳怪气和喜怒交织的不稳定状态。

如果不好好修行，心理能量的出口，要么走身体、要么走精神。东南亚的性产业发达，老张是看得到的，且他作为十亿级的富豪，这个俱乐部的男性已经不能叫玩得花了，性娱乐是一种日常吃饭喝水般平常，老张天天和银行VIP客户经理打交道，这帮人精什么没见过，自由的富豪玩法老张怎么会不知道呢？
