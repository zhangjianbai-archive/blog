黄传科·权威与控制

王老师是不是在老张的系统里泡久了，怎么也一本正经的跟着说起瞎话来了，评论区别删啊，别跟老张一样，评论区只留下赞歌，好的评论，其余的的负面评价一概删除，让自己沉浸在美梦中。王老师好歹也是大学生，好像是武大毕业的吧？也难怪，武大这些年一直出败类，老张也是武大毕业的，真是蛇鼠一窝。

那些评论和文章其他人不懂，难道你还不知道吗？这些文章几乎都是集中在一段时间发布的，主要在21年，25年，还有今年这个时候，这几个时间点分别是，21年老张入驻知乎不久，发现知乎上对今日的几乎都是负面评价，然后再群里发动一批洗地文。

25年由王聪颖发起的，然后一大批今日前家长，毕业生对今日一系列真相的揭露，老张不得不再次发动脑残粉出来发文章，唱赞歌。今年就算财新记者长文对今日的揭露，又一次踩到今日的痛脚了，然后各种脸也不要了，发动水文攻击想淹没知乎。

可是有什么用呢，这些文章都是一个风格，放一点不起眼的成绩，大唱赞歌，对于真正的指控一点也站不住脚，随便哪篇文章，无论老张的还是你们的，丢进去问问AI，AI会告诉你具体的答案，你的这篇文章看似有逻辑，实际上漏洞百出，不信你就把文章放到AI，让它给你评论一下。

你自己就说了为了让统计数据更加客观，中立，也要剔除一些利益相关的人。请问你是不是利益相关的人，为啥只统计好的数据，差的数据一条不放。请问钱莉的《今日学生幸福度调查》，得出今日学生幸福度全国第一，这篇算客观，中立的吗，自己调查自己，然后宣布自己最幸福，有这么办事的人？

这不跟老张一样，把自己很多部分真实，大多数地方参假的成绩，弄出来宣布自己是世界第一，教育界的华为一样可笑。你自己拍脑袋想一想，这些除了自我陶醉，骗一骗脑残粉以外，这么多年了，有哪些知名的学校会正眼瞧一下。

我认为这些道理，你不是不懂，而是就是变坏了，是不是离开新教育，你就没办法生活了，在这个社会上没办法混下去了。然后骗自己说点违心的假话，在这个大染缸里面谋求一个职位，你当初好歹还是一个有理想信念的人，发现了真相，难道还要继续骗自己下去？

下面我再来说说你这篇文章的硬伤，好歹是武汉大学毕业的这点本事不要丢了：

1. 抽样样本来源极度局限，样本天然严重偏倚

你统计的样本只取自知乎平台的公开回答、专栏，并不是全部参与者的随机抽样。

愿意在知乎长篇写文章、回答问题 “为教育发声” 的，大多是有强烈表达动机的人。大量体验普通、不好不坏的家庭，既不会写好评也不会写差评，直接完全消失在统计里。

很多受过不好体验的毕业生、家长，出于家庭隐私、害怕纠纷、心理创伤等原因，根本不愿意在公开网络发帖控诉，不会出现在知乎公开回答中。

简单说：知乎公开留言，不等于清一新教育全部学员的反馈池。用这个池子算正负比例，严重失真，不代表真实学员群体的比例。

2. 筛选标准存在主观裁量空间，容易引入选择偏差

你制定筛的选规则，但规则执行由你一人主观判断：

1）剔除利益相关人员：区分哪些人属于机构相关人员，还不是你自己说了算；

2）负面反馈门槛极高：只有本人 / 自家孩子亲身经历、直接讲自身糟糕遭遇才算有效负评价；凡是引用他人案例、转述他人经历全部剔除。

但对正面反馈，文章没有设置同等严苛的核验门槛：清单里大量是 “我为新教育发声” 这类表态式文章，文章没有进一步核验这些正面叙述者：是否存在隐性利益关联、是否是集体组织批量发声，仅仅看文字自述身份就纳入 “有效正评价”。

正负两方使用的筛选尺度并不对称：负面反馈筛得极严，正面反馈更多采信自述身份，这种不对称会人为抬高正面样本数量。

3. 混淆了 “网络发帖数量” 和 “现实中的问题发生率”

你文中得到 “正评价上百、负评价不足 15”，只是知乎平台上符合你筛选条件的发帖数（谁知道是不是你刻意选取的），不等于实际参与该教育的家庭中满意 / 不满意的人口比例。
