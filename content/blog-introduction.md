# 关于

## 博客介绍

张健柏档案馆由 Klein 发起，收录围绕张健柏（张清一）、今日学堂及相关教育实践的文章，包括前学生、教师和家长的经历、评论，以及张健柏本人的言论。

建立这个博客，是希望这些讨论不再只留在知乎的信息流里。文章通过独立网页保存，方便读者查找、阅读与交流，也让后来者能够了解不同人的经历和看法。

[Klein 的知乎主页](https://www.zhihu.com/people/klein-63-33)

## GitHub 合作方式（MIT）

欢迎通过 [GitHub 仓库](https://github.com/zhangjianbai-archive/blog)参与维护。

- 提交 [Issue](https://github.com/zhangjianbai-archive/blog/issues)，反馈错字、失效链接、排版问题，或提供文章补充与更正线索。
- Fork 仓库后修改代码，通过 [Pull Request](https://github.com/zhangjianbai-archive/blog/pulls)提交改进。涉及文章的修改，请说明出处和修改理由。
